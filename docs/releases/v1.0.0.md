# Mathematica MCP v1.0.0 — Linux MVP

First stable release of the Rust Mathematica MCP service.

## Highlights

- **One centrally managed systemd MCP daemon:** Streamable HTTP on a
  configurable listen address/port, usable by multiple agents on a
  trusted LAN.
- Independent Wolfram sessions and kernel variables for each MCP client.
- Global kernel cap, idle cleanup, bounded evaluation and structured output.
- Native Wolfram/WSTP Rust library, stdio MCP server and interactive REPL.
- Wolfram Language computation, finance helper and Base64 PNG graphics.
- External TOML and native-test-first installer for EndeavourOS/Linux.

## Native acceptance

On 2026-10-15, EndeavourOS with Rust 1.99.0 and Wolfram 15.0 successfully
completed the native WSTP build, all 12 Rust unit tests, strict Clippy,
real-kernel stdio smoke, independent downstream Rust library consumer,
and simultaneous two-agent HTTP tests (independent variables, kernel cap,
ownership, foreign-session rejection, normal shutdown). Deployment built
the release binary, installed/enabled the systemd user service, and
verified a healthy local HTTP endpoint.

## Compatibility and support

v1.0.0 commits to compatibility for the documented Linux Rust API,
MCP tools, transports and TOML settings. Wolfram sessions remain ephemeral
across daemon or transport-session restarts.

This **source-only** GitHub release contains no licensed Wolfram runtime or
WSTP library. There is no crates.io publication, universal Linux binary
or automatic deployment of already running services.

Remaining limitations: second-machine LAN/firewall path unverified;
permanently blocked native WSTP calls may resist cancellation;
Windows unverified. HTTP is intentionally unauthenticated and must be
restricted to fully trusted networks because Wolfram can invoke OS commands.
